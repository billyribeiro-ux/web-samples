1. React stack
Frontend: React
Full-stack framework: None, use React SPA architecture
Backend: Node.js + Express
Database: PostgreSQL
ORM / data layer: Prisma
Auth: Auth.js-compatible custom auth or Clerk
Payments: Stripe
CMS/Admin approach: custom headless CMS/admin built as a separate admin area in the React app backed by the Express API
Styling: Tailwind CSS
Forms/validation: React Hook Form + Zod
Deployment target: Vercel for frontend, Railway/Render/Fly.io or equivalent for backend
Storage/media: S3 or equivalent object storage
Email: Resend
Search: PostgreSQL full-text search with abstraction for future Algolia/Meilisearch upgrade
Analytics: PostHog or GA4-ready hooks

Best for testing: pure frontend + separate backend architecture, dashboard-heavy apps, admin panels, custom product interfaces.
